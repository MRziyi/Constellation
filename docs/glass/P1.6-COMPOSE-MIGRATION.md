# P1.6 — GlassHudActivity Compose 迁移 + phoneDebug 眼镜模拟器

**Created**: 2026-05-26 · **Owner**: Zack · **Target repo**: `~/Code/Projects/Constellation-Glass/`, branch `pivot/baremetal-v2.1`
**Companion**: [GLASS-CLIENT-DESIGN.md](GLASS-CLIENT-DESIGN.md) v2.1 · [GLASS-SDK-REFERENCE.md](GLASS-SDK-REFERENCE.md)

---

## 1. 目标

把 `glass` flavor 的 HUD 渲染从手搭 Android Views 迁移到 Jetpack Compose，达到三个具体效果：

1. **每个 AppState 在 IDE `@Preview(widthDp=480, heightDp=640)` 能直接看到 Rokid Glasses 480×640 上的样子**，不需要真机
2. **per-run styling 真正生效**：`{bold, italic, code, dim}` 通过 `AnnotatedString + SpanStyle` 落地（替代当前 `StyledRunsRenderer.flatten()` 丢 styling 的做法）
3. **phoneDebug flavor 变成"眼镜模拟器"**：OnePlus 9 上接收真 Cortex 帧 + 用同一份 Composable 渲染 480×640 box → 拿一加在手上做 HUD UX 迭代

---

## 2. 关键决策（已定）

| # | 决策 | 理由 |
|---|---|---|
| D1 | **采用 Compose**（仅 ui + foundation，不含 material3） | Halo-Ring 全 Compose；APK +~1.5MB 在 8250 SoC 上零负担；@Preview 是 P1.5 前唯一可视化路径 |
| D2 | **HUD Composables 放 `app/src/main/`**（共享） | glass + phoneDebug 共用同一份视觉；flavor 差异仅在 host 层 |
| D3 | **保留 `glass` + `phoneDebug` 两个 flavor** | Audio + Input 是物理硬件级差异，不可合并 (C-40 仍然成立) |
| D4 | **phoneDebug HUD 改造为"glass 模拟器"** | 同一份 Composable 装在 SYSTEM_ALERT_WINDOW 浮窗里 + 旁边一条 debug 控制条 |
| D5 | **AudioRecord eager close/reopen** (P1.6 内确认现状已是) | 用户拍板"能效第一，不怕冷启动 200ms" |
| D6 | **`Compose Foundation` 只**，不引 Material3 | 单色绿 HUD 不需要 Material；省 APK |
| D7 | **共享 Compose 依赖加在 `implementation`** (不是 `glassImplementation`) | 简单；phoneDebug 反正要用同一份 Composable |
| D8 | **不动 StateMachine / WssClient / Frames** | P1.6 是纯渲染层重写；协议 / 状态机不动 |

### Phase C — RunStyledText + 第一个 @Preview（40 min）

**改**：新建 `composables/RunStyledText.kt`

```kotlin
@Composable
fun RunStyledText(runs: List<StyledRun>, baseSize: TextUnit = HudTheme.bodySize) {
    val annotated = buildAnnotatedString {
        runs.forEach { r ->
            withStyle(SpanStyle(
                fontWeight = if (StyledRunsRenderer.isBold(r.style)) FontWeight.Bold else FontWeight.Normal,
                fontStyle = if (StyledRunsRenderer.isItalic(r.style)) FontStyle.Italic else FontStyle.Normal,
                color = if (StyledRunsRenderer.isDim(r.style)) HudTheme.fgDim else HudTheme.fg,
                fontFamily = if (StyledRunsRenderer.isCode(r.style)) FontFamily.Monospace else FontFamily.SansSerif,
            )) { append(r.text) }
        }
    }
    Text(annotated, fontSize = baseSize)
}

@Preview(widthDp = 200, heightDp = 100, backgroundColor = 0xFF000000, showBackground = true)
@Composable
private fun RunStyledTextPreview() {
    RunStyledText(listOf(
        StyledRun("Hey ", null),
        StyledRun("Jane", "bold"),
        StyledRun(" — see you at 3.", null),
        StyledRun(" via Mail", "dim"),
    ))
}
```

### Phase D — 6 个 AppState Composables（2-3h）

**改**：新建 `composables/AppStateHud.kt`

```kotlin
@Composable
fun AppStateHud(snap: GlassHudState.Snapshot) {
    Box(
        modifier = Modifier
            .fillMaxSize()
            .background(HudTheme.bg)
            .padding(start = HudTheme.sidePadding, end = HudTheme.sidePadding,
                     top = HudTheme.topPadding, bottom = HudTheme.bottomReservedDp)
    ) {
        when (snap.appState) {
            AppState.Idle      -> IdleHud()
            AppState.Listening -> ListeningHud(snap)
            AppState.Thinking  -> ThinkingHud(snap)
            AppState.Card      -> CardHud(snap)
            AppState.Insight   -> InsightHud(snap)
            AppState.Offline   -> OfflineHud(snap)
        }
    }
}
```

每个 state 一个 `@Composable` + 一个 `@Preview(widthDp = 480, heightDp = 640)` 配 mock data。

具体 layout 约定：
- **Listening**：icon "🎤 listening…" → g-wave (21 cells) → partial transcript（max 3 line wrap） → 计时 "0:08"
- **Thinking**：icon "💭 …" → `RunStyledText(detailRuns)` → `RunStyledText(metaRuns)` (smaller)
- **Card**：title `RunStyledText` (titleSize) → ScrollWindow 6 行 body `RunStyledText` (bodySize) → footer 三段 `<CLICK> approve  <LONG> modify  <DOUBLE> kill`
- **Insight**：title → body → linear progress bar (TTL countdown)
- **Offline**："● offline · reconnecting…" + 倒计时

**Done-when**:

## 6. 风险 & 回滚

| 风险 | 应对 |
|---|---|
| Compose Kotlin 编译器扩展版本与 Kotlin 主版本不匹配 → build fail | Phase A 第一步就跑 build；不通过先调版本表（[compose-kotlin-compatibility](https://developer.android.com/jetpack/androidx/releases/compose-kotlin)）|
| phoneDebug `ComposeView` 在 SYSTEM_ALERT_WINDOW 里出现奇怪问题 | Fallback：phoneDebug 不用浮窗，直接用 MainActivity 作 "simulator" 全屏 |
| Compose @Preview 在 IDE 里渲染失败 | 通常是 BOM / tooling 版本；Phase C 就能发现，回退到 ui-tooling 单独版本 |
| 字号在 PV @Preview 里看着对，真机 (Phase P1.5) 完全不对 | 预期内 — HudTheme 集中后改一处即可；P1.5 真机测试本来就要校 densityDpi |

**回滚契约**：每个 Phase 一个 commit。出问题 `git revert <phase commit>` 即可。phoneDebug 用 Compose 走通前，glass flavor 的 Compose 改动也独立可回退。

- 术语 sweep：HANDOFF / GLASS-CLIENT-DESIGN / SoT / TODO / MIGRATION-PLAN 里把 "R08" 误用改为 "Rokid Glasses"（"R08" 是戒指代号）
